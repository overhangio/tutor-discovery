- 💥[Feature] Update the Course Discovery image to use Ubuntu 24.04 as base OS. You will need to rebuild the discovery image with `tutor images build discovery`. If you maintain a custom Dockerfile or patches that `apt install` packages in this image, you may need to switch to the Ubuntu 24.04 package names: many libraries got a `t64` suffix, and some versions changed (e.g. `libicu70` → `libicu74`).
